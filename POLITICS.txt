1. Общие положения
Политика конфиденциальности (далее - «Политика») регулирует порядок обработки данных при использовании программного обеспечения Dynamic Browser (далее - «Браузер»).
Политика определяет принципы, объём и условия обработки данных, а также права пользователя в рамках использования Браузера.

Используя Браузер, пользователь подтверждает, что ознакомлен с данной Политикой и принимает её условия.

2. Принципы обработки данных
Dynamic Browser функционирует на основе следующих принципов:

Принцип минимизации данных - Браузер не собирает и не обрабатывает данные, не необходимые для его работы.

Принцип прозрачности - Политика подробно описывает все процессы, связанные с обработкой данных.

Принцип автономности - Браузер работает локально на устройстве пользователя и не взаимодействует с удалёнными серверами разработчика.

Принцип конфиденциальности по умолчанию — Браузер не использует трекинг, аналитику, телеметрию или скрытые механизмы передачи данных.

3. Сбор и обработка данных
3.1. Отсутствие сбора персональных данных
Dynamic Browser не осуществляет сбор, хранение, анализ или передачу персональных данных, включая, но не ограничиваясь:

имя, фамилия, псевдоним

адрес электронной почты

номер телефона

местоположение

IP‑адрес

уникальные идентификаторы устройства

данные профилей социальных сетей

биометрические данные

платёжные данные

Браузер не создаёт пользовательских профилей и не осуществляет идентификацию пользователя.

3.2. Отсутствие технического сбора
Браузер не собирает:

сведения о версии операционной системы

сведения о версии приложения

технические журналы, отчёты о сбоях, логи ошибок

данные о производительности устройства

информацию о конфигурации оборудования

Dynamic Browser не использует встроенные средства диагностики, телеметрии или автоматической отправки отчётов.

3.3. Отсутствие трекинга и аналитики
Браузер не использует:

рекламные идентификаторы

системы аналитики (Google Analytics, Yandex Metrica и др.)

пиксели отслеживания

SDK сторонних компаний

механизмы fingerprinting

поведенческую аналитику

Браузер не отслеживает действия пользователя, историю просмотров, клики, взаимодействия с интерфейсом или иные поведенческие данные.

4. Данные, передаваемые при посещении сайтов
При загрузке веб‑страниц браузерные протоколы могут автоматически передавать данные, необходимые для функционирования сайтов, включая:

IP‑адрес

cookies, установленные посещаемыми сайтами

User‑Agent

параметры сетевого соединения

Эти данные:

не собираются, не анализируются и не сохраняются Dynamic Browser

передаются напрямую посещаемым сайтам в рамках стандартных интернет‑протоколов

регулируются политиками конфиденциальности соответствующих сайтов

Dynamic Browser не вмешивается в работу сторонних ресурсов и не контролирует их обработку данных.

5. Локальное хранение
Браузер может использовать локальные механизмы хранения данных, включая:

локальное хранилище

кэш

cookies

Эти данные применяются исключительно для обеспечения корректной работы интерфейса, ускорения загрузки страниц и сохранения пользовательских настроек.

Все данные:

хранятся только на устройстве пользователя

не передаются разработчику

могут быть удалены пользователем вручную или при удалении приложения

6. Передача данных третьим лицам
Dynamic Browser:

не передаёт данные третьим лицам

не продаёт данные

не предоставляет данные по запросу коммерческих организаций

не использует внешние серверы для обработки данных

Исключения отсутствуют.

7. Взаимодействие со сторонними сервисами
При посещении сайтов пользователь может взаимодействовать со сторонними сервисами, которые имеют собственные политики конфиденциальности.
Dynamic Browser:

не контролирует работу сторонних сервисов

не несёт ответственности за их методы обработки данных

не имеет доступа к данным, которые пользователь передаёт таким сервисам

Пользователь самостоятельно несёт ответственность за ознакомление с политиками сторонних ресурсов.

Dynamic Browser распространяется на условиях лицензии MIT, что означает:

пользователь имеет право свободно использовать, копировать, изменять и распространять приложение

программное обеспечение предоставляется «как есть»

разработчик не предоставляет гарантий любого рода

разработчик не несёт ответственности за прямой или косвенный ущерб, возникший в результате использования приложения

при распространении производных версий необходимо сохранять уведомление об авторских правах и текст лицензии MIT

9. Права пользователя
Пользователь имеет право:

прекратить использование Браузера в любой момент

удалить приложение

удалить все локальные данные, связанные с работой Браузера

использовать, модифицировать и распространять приложение в соответствии с лицензией MIT

Dynamic Browser не ограничивает пользователя в его правах и не создаёт технических барьеров для удаления данных.

10. Безопасность данных
Dynamic Browser:

не передаёт данные через сторонние каналы

не использует удалённые серверы

не хранит данные вне устройства пользователя

Безопасность данных полностью зависит от состояния устройства пользователя, его операционной системы и установленных приложений.

11. Обновления Политики
Политика может быть изменена в случае обновления функциональности Браузера или изменения юридических требований.
Актуальная версия Политики всегда доступна на сайте.
