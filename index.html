1. Общие положения

Настоящая Политика конфиденциальности регулирует порядок обработки данных при использовании приложения Dynamic Browser (далее — «Браузер»).
Используя Браузер, пользователь подтверждает, что ознакомлен с данной Политикой.

2. Сбор и обработка данных

2.1. Отсутствие сбора персональных данных
Dynamic Browser не собирает, не обрабатывает и не передаёт какие‑либо персональные данные пользователей.

2.2. Отсутствие технического сбора
Браузер не собирает:
• сведения о версии операционной системы;
• сведения о версии приложения;
• технические логи, ошибки, отчёты о сбоях;
• данные об устройстве или его конфигурации.

2.3. Отсутствие трекинга
Браузер не использует трекеры, аналитические инструменты, системы мониторинга поведения, рекламные идентификаторы или любые механизмы слежения.

3. Данные, передаваемые при посещении сайтов

При загрузке веб‑страниц могут автоматически передаваться данные, необходимые для работы сайтов (например, IP‑адрес, cookies, User‑Agent).
Эти данные:
• не собираются и не сохраняются Браузером;
• передаются напрямую посещаемым сайтам в рамках стандартной работы интернета.

4. Локальное хранение

Браузер может использовать локальное хранилище, кэш и cookies исключительно для обеспечения работы интерфейса и сохранения пользовательских настроек.
Все данные хранятся только на устройстве пользователя и не передаются разработчику.

5. Передача данных третьим лицам

Dynamic Browser не передаёт, не продаёт и не предоставляет какие‑либо данные третьим лицам.
Исключения отсутствуют.

6. Сторонние ресурсы

При посещении сайтов пользователь взаимодействует со сторонними сервисами, которые имеют собственные политики конфиденциальности.
Dynamic Browser не контролирует и не несёт ответственность за обработку данных такими сервисами.

7. Права пользователя

Пользователь вправе:
• прекратить использование Браузера в любой момент;
• удалить приложение и все локальные данные.

8. Изменения Политики

Политика конфиденциальности может быть обновлена.
Актуальная версия всегда доступна в меню Браузера.
